# **App Name**: VocalLink AI

## Core Features:

- Speech-to-Text: Record user's speech and convert it to text for sending to the backend.
- Text-to-Speech: Receive text from the backend and convert it to speech using ElevenLabs API.
- Chat Interface: Display the conversation in a clean, real-time chat interface with indicators for the source of the message (user or AI).

## Style Guidelines:

- Primary color: Dark blue (#1A237E) for a professional and modern feel.
- Secondary color: Light gray (#EEEEEE) for backgrounds and subtle contrasts.
- Accent: Teal (#00BCD4) for interactive elements and highlights.
- Clean and simple layout with a clear distinction between user input and AI output.
- Use clear and recognizable icons for microphone, sending, and other actions.
- Subtle animations for message bubbles and loading states to enhance user experience.
